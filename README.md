# ⏱ ChatGuard — Неотвеченные чаты

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Тревожные уведомления, когда покупатель ждёт ответа: если сообщение висит без ответа
дольше N минут — плагин напишет вам в Telegram. Больше никаких потерянных клиентов,
которые ушли к конкуренту, пока вы спали или были заняты.

## Возможности

- ⏱ **Таймер ожидания** — сообщение покупателя берётся на контроль; ваш ответ
  (с сайта, из приложения или автоответ/автовыдача бота) снимает его с контроля.
- 🚨 **Уведомление** — «Покупатель ждёт ответа уже 35 мин.!» с именем покупателя,
  ссылкой на профиль и текстом последнего сообщения.
- 🔁 **Повторные напоминания** (опционально) — каждые X минут, пока не ответите.
- **Умная фильтрация**: системные сообщения FunPay («заказ подтверждён», «новый отзыв»,
  возвраты и т.п.) игнорируются; трекаются живые сообщения и «покупатель оплатил заказ».
- Повторные сообщения покупателя **не сбрасывают таймер** (ждёт с момента первого
  unanswered-сообщения), но превью в уведомлении — свежее.
- 💾 Состояние переживает рестарт Кардинала.
- Меню **`/chatguard`**: список ждущих чатов с возрастом, настройки, «очистить всё».

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-ChatGuard/main/chat_guard.py -O plugins/chat_guard.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование и настройки

Команда **`/chatguard`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🟢/🔴 Мониторинг | Включить/выключить плагин |
| ⏳ Порог: 30 мин. | Через сколько минут молчания бить тревогу (1–1440) |
| 🔁 Повтор: ВЫКЛ/15 мин. | Повторные напоминания, 0 = одно напоминание (0–1440) |
| 🧹 Очистить список | Сбросить все таймеры (например, после отпуска) |

Главное меню показывает список чатов, которые сейчас ждут ответа, с возрастом
(🚨 — уже дольше порога, 🕐 — ещё в пределах).

## Важно знать

- Отсчёт начинается **с момента запуска Кардинала** (для сообщений, пришедших до
  запуска, история не перечитывается — так устроен Runner).
- Уведомления идут через тип «Прочие уведомления (плагины)» — проверьте, что он
  включён в настройках уведомлений ПУ.
- Сообщения, отправленные ботом Кардинала (автовыдача, автоответ, приветствия),
  считаются ответом — таймер снимается.
- Настройки: `storage/plugins/chat_guard/settings.json`.

## Состав репозитория

- `chat_guard.py` — плагин (класть в `plugins/`).
- `tests_plugin_chat_guard.py` — тесты (37 проверок на моках: трекинг сообщений,
  классификация мой/бот/системный, пороги, повторы, весь Telegram-UI, настройки).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_chat_guard.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_chat_guard.py
  ```
